# Security policy

## Reporting a vulnerability

Report a vulnerability privately through [GitHub Security Advisories](https://github.com/nwaoga/loft/security/advisories/new).

Please do not open a public issue for a security report. Do not include access tokens, private file paths, or the contents of documents.

Loft keeps folders, the index, and chat history on the computer where it runs. A report should describe the defect (for example a path that is opened or executed when it should not be). It does not need a copy of the files that triggered it.

## Supported versions

Security fixes go to the current `main` branch. Loft has no older release branch.
