Set up your first models.

Open the settings gear. Under Chat model, download and select Qwen2.5 3B Instruct. This model writes your answers.

Under Embedding model, select Nomic Embed Text v1.5. It finds passages related to your question. Once both models are active, you can index folders and ask questions offline.

From a folder
to its sources.

  1. Choose what Loft can read

    Open Folders and add a folder of project notes, or drag the folder onto Loft. Wait for indexing to finish.

  2. Ask from your desktop

    Press Ctrl+Shift+Space on Windows or Cmd+Shift+Space on Mac to open Loft. In Ask, try a question with an answer in your notes, such as “Which tasks are still open for release?”

  3. Check the original

    Expand the sources beneath a reply to read the excerpts. Open a document or reveal a source file in its folder.

Choose how Loft runs on battery.

Open Settings → Performance & battery. Choose a profile for When plugged in and another for When running on battery. Enable Switch when the power source changes to use both.

The Chat and Embeddings rows show the device each model actually uses. If Loft falls back to another engine, the panel explains why.

Test your own hardware.

In the same panel, open Test performance and run the test. Loft asks each installed engine the same question with your chat model. Compare time to first token for responsiveness and tokens per second for generation speed.

On the laptop shown, the RTX 4050 reached 58 tokens/s, Intel Iris Xe reached 8.7, and CPU reached 4.3. To compare battery use, unplug and test again.
